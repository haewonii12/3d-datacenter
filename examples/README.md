# 업로드 예시

앱 상단 **데이터 ▾ → 파일 불러오기…**(또는 화면에 끌어다 놓기)로 불러올 수 있는 파일입니다. 형식과 규칙의 자세한 설명은 [../README.md](../README.md#데이터-형식)에 있습니다.

| 파일 | 내용 |
|---|---|
| `upload-example.csv` | 현장 레코드 형식 CSV (UTF-8 BOM). 경고 0건 |
| `upload-example.json` | 같은 내용의 JSON 레코드 배열 |
| `violations.csv` | 규칙 위반을 일부러 넣은 파일. 불러오면 경고 8건과 빨간 표시를 확인할 수 있습니다 |

## 열

`build_name, floorspace_name, company, rack_name, device_position, device_name` (선택: `total_u`)

- 한 행 = 장비 1대. `device_position`·`device_name`이 빈 행은 빈 랙.
- `floorspace_name`: `3A0401` = 3층 A구역 4번째 줄 1번 칸. 여러 칸을 차지하는 랙은 `"3A0402,3A0403"`처럼 따옴표 안에 쉼표로.
- `device_position`: `3U (29-31)` = 높이 3U, U29–U31.
- 한글 머리글도 됩니다: `빌딩/건물/데이터센터`, `상면`, `회사`, `랙`, `장착위치`, `장비/장비명`.
