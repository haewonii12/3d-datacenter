## Goal
데이터센터의 층/row/col 랙 배치와 랙 내 unit별 서버, 서버별 서비스를 브라우저에서 3D로 탐색하는 정적 웹앱. 층 단위로 랙 점유 상황을 한눈에 보고, 랙 → 서버 → 서비스로 드릴다운하며, 검색으로 특정 서버/서비스 위치로 바로 이동한다.

## Constraints
- 기술: Vite + three.js (vanilla JS), 백엔드/DB 없음, 정적 빌드
- 위치: 새 프로젝트 디렉터리 `~/dc-rack-3d` (현재 cwd의 whatsmyagentdoing과 무관)
- 데이터: 실데이터 미보유 → 샘플 생성 스크립트로 JSON 생성. 실데이터는 이후 같은 스키마로 교체
- 규모: 3–5층, 층당 랙 100–300개, 랙 42U, 서버 총 수천 대. 전체 뷰는 모든 층의 랙(최대 ~1500개)을 InstancedMesh로 렌더, 층/랙 뷰에서는 서버 박스를 해당 랙(또는 층)만 생성. 60fps 목표
- 서버 높이(U 수) 필드가 원 데이터에 없을 수 있음 → `height_u` 없으면 1U로 간주
- 데이터 스키마(초안):
  - rack: `{ id, floor, row, col, total_u: 42 }`
  - server: `{ id, hostname, ip, rack_id, unit, height_u? }` (unit = 하단 시작 U)
  - service: `{ name, team, status: "ok"|"warn"|"down" }` (server.services[])
  - floor: `{ floor, rows, cols }` (슬롯 그리드 크기 → 빈 슬롯 계산)

## Non-Goals
- 데이터 편집, 로그인/권한, 실시간 모니터링 연동, DB/API 연동, xlsx 직접 파싱
- (변경) 전체 뷰에서는 여러 층 동시 렌더링 허용 — 단 서버 단위 디테일은 층/랙 뷰에서만
